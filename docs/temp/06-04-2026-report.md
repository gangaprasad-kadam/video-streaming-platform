## Folder & File Descriptions

### `nginx/nginx.conf`
NGINX reverse proxy gateway. Routes incoming requests to the correct microservice based on URL prefix (`/auth/` → user-service, `/videos/` → video-service). Handles HLS range requests and SSE streaming with special headers.

---

### `services/shared/`
Shared Python library mounted read-only into every service container.

| File | Description |
|------|-------------|
| `__init__.py` | Re-exports all symbols for easy import |
| `exceptions.py` | Base exception classes: `AppException`, `NotFoundError`, `AuthError`, `ForbiddenError`, `ConflictError`, `RateLimitError` |
| `schemas.py` | Standard API response envelopes: `SuccessResponse[T]`, `ErrorResponse`, `PagedResponse[T]` |
| `dependencies.py` | `get_current_user()` — validates session cookie against Redis |
